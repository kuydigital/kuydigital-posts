# Photo library

Photos that `photo` posts may use. A post never uses a photo that is not listed here, and never uses the same photo twice.

The scheduled run cannot download from Unsplash or Pexels itself, so photos come from Oliver: download a royalty-free photo (or use one of your own), put the file in this folder, and add one row below. Good subjects: desks, screens, laptops, workspaces, Metro Manila streets and malls, sketches, hands at work. No people's faces up close, no visible brand logos, no screenshots of other people's apps or sites.

Rules for each file:

- At least 1600 px wide, JPG or PNG, under 5 MB.
- License must be one of: `Unsplash License`, `Pexels License`, `CC0`, `Public domain`, `Own photo`.
- `credit` is printed small on the image (leave it as `-` for an own photo).
